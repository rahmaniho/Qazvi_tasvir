## ۴. جایگزینی تصاویر ناوگان (Fleet Images)

برای تغییر تصاویر بخش «ناوگان ترابری»، کافی است فایل‌های زیر را با تصاویر واقعی ناوگان شرکت بازنویسی کنید (نام فایل را تغییر ندهید):

| کارت | مسیر فایل JPG | مسیر فایل WebP (اختیاری ولی توصیه‌شده) | اندازه پیشنهادی |
|---|---|---|---|
| اتوبوس | `assets/images/bus-fleet.jpg` | `assets/images/bus-fleet.webp` | ۱۰۰۰×۷۵۰ (نسبت ۴:۳) |
| مینی‌بوس | `assets/images/minibus-fleet.jpg` | `assets/images/minibus-fleet.webp` | ۱۰۰۰×۷۵۰ (نسبت ۴:۳) |
| ون | `assets/images/van-fleet.jpg` | `assets/images/van-fleet.webp` | ۱۰۰۰×۷۵۰ (نسبت ۴:۳) |

نکات مهم:

1. کد HTML از تگ `<picture>` استفاده می‌کند؛ اگر نسخه `.webp` موجود نباشد، مرورگر به‌طور
   خودکار فایل `.jpg` را بارگذاری می‌کند — پس حذف فایل WebP باعث خطا نمی‌شود.
2. برای تولید نسخه WebP می‌توانید از ابزارهایی مثل `cwebp`، Squoosh یا TinyPNG استفاده کنید
   (نمونه دستور: `cwebp -q 78 bus-fleet.jpg -o bus-fleet.webp`).
3. تصاویر با `loading="lazy"` و `decoding="async"` بارگذاری می‌شوند و تا زمان آماده شدن،
   **اسکلتون شیمر** نمایش داده می‌شود.
4. اگر فعلاً تصویر واقعی ندارید و می‌خواهید از تصاویر رایگان اینترنتی استفاده کنید، می‌توانید
   همان نام فایل را از این آدرس‌های نمونه دانلود و ذخیره کنید:
   - اتوبوس: `https://images.unsplash.com/photo-1544620347-c4fd4a3d5957`
   - مینی‌بوس: `https://images.unsplash.com/photo-1570125909232-eb263c188e7e`
   - ون: `https://images.unsplash.com/photo-1527786356703-4b100091cd2c`

   (پیشنهاد ما: به‌دلیل پایداری، سرعت و سئو، تصویر را دانلود و به‌صورت محلی در
   `assets/images/` نگه دارید؛ استفاده مستقیم از لینک خارجی باعث کندی بارگذاری می‌شود.)

## ۵. جایگزینی لوگوهای برندها (Brand Logos)

لوگوهای فعلی، **وردمارک متنی (Text-based)** با طراحی اختصاصی هستند (طبق راه‌حل جایگزین مورد
تأیید) و نشان رسمی تجاری شرکت‌های سازنده محسوب نمی‌شوند. برای جایگزینی با لوگوی رسمی،
فقط همان فایل را با فرمت SVG بازنویسی کنید:

| برند | مسیر فایل |
|---|---|
| اسکانیا (Scania) | `assets/logos/scania.svg` |
| ولوو (Volvo) | `assets/logos/volvo.svg` |
| مرسدس بنز (Mercedes-Benz) | `assets/logos/mercedes.svg` |
| ایویکو (Iveco) | `assets/logos/iveco.svg` |
| ایران خودرو دیزل (IKD) | `assets/logos/irankhodro.svg` |

- نسبت پیشنهادی لوگوها: **۲۰۰×۱۱۰** (در صفحه با حداکثر عرض ۱۶۸px نمایش داده می‌شوند).
- حالت پیش‌فرض: `grayscale(100%)` با شفافیت ۰.۷ — با هاور به حالت رنگی و شفافیت کامل درمی‌آید.

## ۶. سیستم طراحی (Design System)

- **پالت:** Navy `#0A2540` · Navy Deep `#061829` · Teal `#0E4B6E` · Amber `#F59E0B` ·
  Sky `#0EA5E9` · Surface `#F7F9FC` · Success `#10B981`
- **تایپوگرافی:** Vazirmatn (فارسی) + Inter (اعداد لاتین) از CDN با `preconnect`
- **سبک بصری:** Glassmorphism 2.0 — `backdrop-filter: blur(24px) saturate(180%)`،
  مرز نوری گرادیانی با `mask-composite`، مش گرادیان چندلایه و بافت نویز SVG با شفافیت ۴٪
- **موشن:** `cubic-bezier(0.22, 1, 0.36, 1)` — ورود بخش‌ها با Intersection Observer،
  ورود پله‌ای کارت‌های ناوگان (Stagger ۱۰۰ms) و شمارش اعداد آماری (Count-up)
- **احترام به `prefers-reduced-motion`** برای همه انیمیشن‌ها

## ۷. دسترس‌پذیری و سئو

- `lang="fa"` و `dir="rtl"`، ساختار سمنتیک (`header`, `nav`, `main`, `section`, `article`, `footer`)
- یک `H1` در صفحه و ترتیب صحیح `H2` → `H3`
- `alt` توصیفی فارسی برای همه تصاویر، `aria-label` برای دکمه‌های آیکونی
- ناوبری کامل با کیبورد، `focus-visible` با حلقه ۳ پیکسلی آبی، لینک «پرش به محتوا»
- متادیتای Open Graph، Twitter Card، Canonical و **JSON-LD** نوع `Organization` + `LocalBusiness`
  به‌همراه `hasOfferCatalog` برای خدمات بازرگانی و ترابری
- جایگزین `<noscript>` برای نمایش کامل بخش‌ها در صورت غیرفعال بودن جاوااسکریپت

## ۸. انتشار روی GitHub Pages

1. مخزن را به شاخه `main` پوش کنید.
2. در GitHub به `Settings → Pages` بروید.
3. در بخش **Source** گزینه `Deploy from a branch` را انتخاب کنید.
4. شاخه `main` و پوشه `/ (root)` را انتخاب و ذخیره کنید.
5. پس از چند دقیقه سایت روی آدرس زیر فعال می‌شود:
   `https://rahmaniho.github.io/Qazvi_tasvir/`

> اگر سایت روی دامنه اختصاصی (`qazvintasvir.ir`) منتشر می‌شود، مقدار
> `<link rel="canonical">` و آدرس‌های داخل `sitemap.xml` / `robots.txt` را به‌روزرسانی کنید.
